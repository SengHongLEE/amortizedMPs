# MP_full_a1 jump 替代 pronk 训练实验

## 目标
独立训练五原语双 policy：保留 walk/trot/canter/bound，以 contact/phase 状态机 jump 替代 pronk；在相同 gap/hurdle 评测条件下与现有基线比较。

## 阶段
1. [x] 核对当前代码、训练资源、旧基线、控制器与评测入口。
2. [x] 先写 jump 控制器与实验任务契约测试，再实现隔离的控制器/任务/训练入口。
3. [x] smoke 验证动作维度、原语语义、checkpoint 加载与评测链。
4. [x] 完成 V1 150 轮、熵系数与 canter 步长训练消融；依据跳跃选择概率坍缩早停。
5. [x] 完成 V1、V2 的真值触发物理扫描，定位起跳速度、落点和连续动作屏蔽问题。
6. [x] 实现隔离的 V3：保留助跑步态，以现有连续动作锁存六个跳跃参数；完成两个种子的配对物理评测。
7. [x] V3 新策略训练到第 20 轮并早停，评测第 10/20 轮与原 checkpoint。
8. [x] 汇总结果、限制及复现命令；相关单元测试、语法和差异检查通过。

## 约束
- 不覆盖现有 train.py、默认 MP_full_a1 注册、旧评测脚本和用户已有改动。
- 训练和评测必须共享完全相同的 jump 动力学；不能用 pronk 动力学加载 jump checkpoint。
- 不能把 smoke 训练当作性能结论；需要足量更新和同设置评测。
