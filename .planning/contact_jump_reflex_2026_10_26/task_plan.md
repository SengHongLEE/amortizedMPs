# MP_full_a1 contact jump reflex 验证

## 目标
在不修改既有训练、评测脚本和默认任务配置的条件下，构造只由接触与内部状态触发的一次性跳跃探针，配对比较障碍通过率及跳跃事件。

## 阶段
1. [x] 核对现有控制链、评测入口、GPU 状态及可用 checkpoint。
2. [x] 先写接触跳跃状态机测试，再实现隔离的实验模块。
3. [x] 新建独立评测入口，复用现有 checkpoint 与地形指标；检查初始状态一致。
4. [x] 小样本物理仿真：基线、reflex，在 gap 与 hurdle 上比较；记录触发、离地、碰撞及通过率。
5. [x] 汇总结论、限制与复现命令。

## 约束
- 不改 train.py、既有评测脚本、默认 MP_full_a1 配置。
- 不打断用户正在运行的训练。
- 旧五原语 checkpoint 无 jump 输出；实验用障碍前的 oracle arm 模拟策略提前选中 jump，上界验证需明确标注，真正学习效果需新训练。
