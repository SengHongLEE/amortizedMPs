# 本体地形任务的平衡位置动作改造

用户已同意将 12 维关节残差替换为扩展动力系统的平衡位置目标。
在现有工作区实施，保留已有地形、步态和训练算法改动。

动作固定为 `[gait, amplitude(4), bx(4), by(4), bz(4)]`，每组腿序 FL/FR/RL/RR。
三个方向的目标单位为米，通过临界阻尼二阶系统产生实际轨迹偏移；
接触或名义支撑期使用较低速度上限。默认目标范围 ±(0.04, 0.025, 0.04) m。
只扩展本任务的动力学类，不改变其他任务的动作语义。

- [x] 新增行为测试：零动作兼容、三个轴和四条腿映射、滤波收敛、速度限制、
  支撑高度调整、部分重置、极端动作的运动学约束、内部观测和噪声。
- [x] 新增 `utils/dynamics/a1/equilibrium_dynamics.py`：
  二阶平衡位置状态、归一化内部观测、工作空间处理及有界 IK。
- [x] 修改 `envs/a1/mp_proprio_terrain_config.py` 和 `mp_proprio_terrain.py`：
  参数接口、动作版本检查、移除关节残差、接入新控制器、观测和重置。
  动作缩放只作用于连续部分，关节目标使用 URDF 硬限位内的裕量。
- [x] 运行针对性测试，以及 CPU/CUDA 的实际环境与策略更新 smoke。
  检查有限值、目标限位、动作/观测维度和部分重置。
- [x] 更新任务文档，注明旧 checkpoint 不兼容，运动学约束不等于楼梯通过保证。

验证入口：`legged_gym/tests/test_equilibrium_dynamics.py`、
`legged_gym/tests/smoke_mp_terrain.py --task proprio`。
使用 `cpgil` Python，关闭字节码写入，不启动长期训练。

验证过程中修复：

- runner 在无环境需要动作更新时仍调用 actor，导致 Categorical 空批次异常。
  训练与推理都保持原有动作直到下一决策时刻；加入 2 项回归测试。
- 原有审计硬编码四步态，与当前六步态表维度不匹配；审计现在覆盖
  497,664 个单腿样本，并分别报告原始请求与有界 IK 的结果。
- 极端向内/向上偏移接近髋轴奇异区，加入 0.06 m 矢状面距离裕量；
  对已复现的毫米级足端变化放大问题加入回归测试。

最终验证：14 项动力系统/环境契约测试、48 项地形测试、2 项调度测试通过。
CPU 平面带噪声短 PPO 更新、checkpoint 往返和推理通过；CUDA 配置地形、
课程升降级/自动及部分重置通过；CPU heightfield 关闭课程并固定第 9 行通过。
